# Kohinoor GSAP Portfolio — Tailwind CSS

A six-route React portfolio assignment using:

- React
- React Router
- GSAP + ScrollTrigger
- Tailwind CSS v4
- Lucide React
- Vite

## Routes

- `/` Home
- `/about` About
- `/skills` Skills
- `/projects` Projects
- `/projects/devflow` Project Details
- `/contact` Contact

## Run

```bash
npm install
npm run dev
```

The project is intentionally scoped so it can be completed/polished in roughly four hours.
Replace the placeholder portrait and project preview with your own assets.
